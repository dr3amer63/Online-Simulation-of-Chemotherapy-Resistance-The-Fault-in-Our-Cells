# Code of Conduct

## Our pledge

We want this project to be a respectful place for learners, educators, and contributors working on an educational cancer-biology lab port.

## Expected behavior

- Be kind and professional in issues, pull requests, and discussions
- Assume good intent; critique ideas and code, not people
- Credit others’ work, including the original MIT BLOSSOMS / Koch Institute lesson authors
- Do not claim MIT or Koch Institute endorsement

## Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Trolling, insulting comments, or sustained disruption
- Publishing others’ private information
- Spam or off-topic promotion

## Enforcement

Maintainers may edit or close comments, lock discussions, reject contributions, or block accounts that violate this code.

Report concerns by opening a GitHub issue (or a private GitHub security advisory if the matter is sensitive). If that is not appropriate, contact the maintainer listed in [README.md](README.md).
